Como criar o token
  1. No GitHub, abra Settings › Developer settings › Fine-grained personal access tokens › Generate new token.
  2. Em Repository access, escolha só o repositório do portfolio.
  3. Em Permissions, dê a Contents o acesso Read and write. Nada além disso.
  4. Defina uma validade (ex.: 90 dias) e renove quando expirar.
  5. Copie o token e cole aqui. Se suspeitar de vazamento, revogue-o no GitHub: o painel para de funcionar na hora.
